# KGB NextGen Solutions Ltd — site vitrine

Portfolio de l'entreprise (Maurice) : services, projets en cours, équipe, contact.
Français sur `/`, anglais sur `/en`.

## Démarrer
```bash
pnpm install
pnpm dev
```

## Références
- `docs/DECISIONS.md` : décisions validées (contenu, charte, animation).
- `PRODUCT.md`, `DESIGN.md` : contexte de design (impeccable).
- `CLAUDE.md` : règles pour les agents.

Stack : Next.js 16, Tailwind CSS 4, Motion, next-intl, Resend — hébergé sur Vercel.
